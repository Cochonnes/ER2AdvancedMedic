# ER2AdvancewdMedic
Advanced medic mod for Easy Red 2, with assets from ArmA 3 "ACE"


# Credits & License

**ER2AdvancedMedic** — an enhanced medical system for *Easy Red 2*, modeled on Arma 3's ACE3.
Created by **Cochonnes**.

This mod includes image assets from the **ACE3** project for Arma 3.

- **Assets:** Medical interface icons and graphics
- **Source module:** `addons/medical_gui` (extracted from `ace_medical_gui.pbo`)
